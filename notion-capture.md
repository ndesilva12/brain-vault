# Notion capture routing

Standing rules for Jimmy and any other assistant. Source: Norman, 2026-09-04 (ported from Claude instructions); LIST-as-SoT + checkbox cleanup updated 2026-09-21 (delete-checked-forever; no Done section).

**Never** touch or look at Apple Reminders. **Never** edit the Notion Why note.

---

## LIST = source of truth for prioritized to-dos

**Page:** [LIST — Norman / VAULT / TASK LIST](https://app.notion.com/p/3aebedd4141981f58664ed01bbb1242f)

**Shape:** ONE open checkbox list only. **No Done section / Done / Archive.**

### Checkboxes (delete-on-check)
- Open items are `- [ ]` (unchecked) or `- [x]` (Norman tapped done in Notion).
- Checking does **not** auto-delete. Jimmy **deletes checked items forever** at the daily 8am brief and on "sweep the list" / whenever Jimmy touches LIST.
- A checked box **is** Norman's approval to delete forever. Never move checked items to Done/Archive; never keep a Done section.
- Unchecked items that look finished from outside evidence stay unchecked until Norman checks them (optional brief note only).

### Everyday flow
- Triggers (`list`, `to-do`, `my list`, `vault list`, `project list`, `tasks`, plus clear add / what's on my list / mark done) operate on this page.
- **Add without asking:** append as `- [ ] **YYYY-MM-DD** — <action>` when real work piles up from email, texts, calendar, Inkbox, or chat. Deduplicate. Mention the add.
- Do not reorder the page unless Norman asks; the morning brief may present a today-ordered view without rewriting Notion.
- Never use Apple Reminders for these.

### Morning brief (daily 8am)
1. Fetch LIST.
2. Delete `- [x]` items forever (no Done move).
3. Brief: Deleted (checked) → Open priority view → today's ten → overnight adds → optional maybe-finished (still unchecked).
4. Deliver in Jimmy / Grok Bot chat only (no iMessage for the brief).

Ideas and Thoughts remain separate capture pads (below). They are **not** the task SoT.
