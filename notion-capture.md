# Notion capture routing

Standing rules for Jimmy and any other assistant. Source: Norman, 2026-09-04 (ported from Claude instructions); LIST-as-SoT + checkbox policy revised 2026-09-21 (Sunday purge + morning reorder; no Done section).

**Never** touch or look at Apple Reminders. **Never** edit the Notion Why note.

---

## LIST = source of truth for prioritized to-dos

**Page:** [LIST — Norman / VAULT / TASK LIST](https://app.notion.com/p/3aebedd4141981f58664ed01bbb1242f)

**Shape:** ONE continuous checkbox list only. **No Open/Done sections / Done / Archive.**

### Checkboxes (leave checked; Sunday purge)
- Open work is `- [ ]` (unchecked) or `- [x]` (Norman tapped done in Notion).
- When Norman checks an item, **leave it checked** — do **not** delete it on daily runs.
- **Each morning:** reorder the page so **unchecked items are first**, **checked items at the bottom**.
- **Sunday morning ONLY:** permanently delete all checked (`- [x]`) items. Never delete checked items on other days.
- Never move checked items to Done/Archive; never create Open/Done sections.
- Unchecked items that look finished from outside evidence stay unchecked until Norman checks them (optional brief note only).

### Everyday flow
- Triggers (`list`, `to-do`, `my list`, `vault list`, `project list`, `tasks`, plus clear add / what's on my list / mark done) operate on this page.
- **Add without asking:** append as `- [ ] **YYYY-MM-DD** — <action>` when real work piles up from email, texts, calendar, Inkbox, or chat. Deduplicate. Mention the add. Bots may auto-append unchecked dated items.
- Morning reorder (unchecked first / checked last) is standing; do not invent other reorders unless Norman asks.
- Never use Apple Reminders for these.

### Morning brief (daily 8am)
1. Fetch LIST.
2. Reorder: unchecked first, checked at bottom.
3. **Sunday only:** permanently delete all `- [x]` items. Other days: leave checked items on the page.
4. Brief: Sunday purge (or n/a) → checked overnight still on LIST (non-Sunday) → unchecked priority view → today's ten → overnight adds → optional maybe-finished (still unchecked).
5. Deliver in Jimmy / Grok Bot chat only (no iMessage for the brief).

Ideas and Thoughts remain separate capture pads (below). They are **not** the task SoT.
