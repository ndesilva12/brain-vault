# LIST — bot write policy (permanent)

**Page:** [LIST — Norman](https://app.notion.com/p/3aebedd4141981f58664ed01bbb1242f)

**Standing permission (reaffirmed 2026-09-16; LIST shape revised 2026-09-21):** Every Norman assistant may **auto-append open to-dos** anytime they judge something worth his attention or remembering to do. **No ask-first.**

## Rules

1. Append as an unchecked checkbox: `- [ ] **YYYY-MM-DD** — <concise action>`.
2. Deduplicate obvious duplicates before adding.
3. Prefer action verbs and enough context that Norman can act without the chat.
4. **LIST is one continuous checkbox list only — no Open/Done sections.** When Norman checks a box, **leave it checked.**
5. **Each morning:** reorder so unchecked items are first and checked items are at the bottom.
6. **Sunday morning ONLY:** permanently delete all checked (`- [x]`) items. Do **not** delete checked items on daily (non-Sunday) sweeps.
7. Never move checked items to Done/Archive; never create a Done section.
8. Never use Apple Reminders.
9. Not for ideas/thoughts/journal — those go to IDEAS & NOTES / THOUGHTS / JOURNAL.

Jimmy reorders LIST every morning (unchecked first / checked last). Sunday morning is the only purge of checked items. Auto-append of unchecked dated items is still OK. 8am brief delivery is Jimmy chat only (no iMessage).
