# Inner Circle

Personal relationship CRM for Norman — family and close friends only (not Cinderella / Dex / prospecting).

## Sources

- Narrative SoT: vault `people.md` (fetch fresh each ask)
- Recency: Drive folder **iMessage** → `imessage-latest.json` (daily) + dated dumps; distill durable facts here same session
- PII / phones: private **Norman Network Master** sheet only — never into this folder
- Live gifts SoT: [Inner Circle Gifts & Occasions](https://docs.google.com/spreadsheets/d/1rP89kVjaDqgT9CdaDrCHs2DyFxoJRxAcffSBCrv0Xyg/edit) (People · Plan · Gift History · Holidays)

## Files

- `life-events.md` — babies, moves, health, open confirms
- `occasions.md` — birthdays, holidays, gift ideas (pointer to sheet)

## Rules

- Track occasions, gifts (targets / acquired / past), and life events
- **Never draft texts, emails, or messages from Norman to inner-circle people** — they know his voice; he writes on the spot. No check-in / thank-you copy unless he explicitly asks for one
- Never send messages unless he explicitly asks
- Sensitive notes stay factual — no gossip
